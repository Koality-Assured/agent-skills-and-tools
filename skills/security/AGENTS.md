# Security skills

Defensive, evidence-backed security audit skills for directory services, endpoints, and policy configuration.

## Rules

- Follow the shared contract in [`../skill-conventions.md`](../skill-conventions.md). In the full ai-router checkout, also follow `ai-tooling/AGENTS.md`; standalone repositories follow their destination root `AGENTS.md`.
- Audits are read-only by default and require an explicit authorized scope before collection.
- Keep collection separate from evaluation; reference material is advisory and never an execution instruction.
